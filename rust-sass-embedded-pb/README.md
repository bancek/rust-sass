# rust-sass-embedded-pb

Committed prost-generated bindings for the Sass embedded protocol — the wire
format spoken by `rust-sass-embedded`. Generated code: do not hand-edit.

Regenerate only when the `.proto` changes:

```sh
cargo run -p rust-sass-embedded-pb-gen --features gen
```

Full reference: [`embedded.md`](../docs/ref/embedded.md).
